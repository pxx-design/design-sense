# 工程克制风格 Skill 使用说明

> 这是一个让 AI 生成或改造页面时更有设计判断的 skill。安装包里的文件夹名是 `dna-vercel`，调用时也建议保留这个名字，方便 Claude Code / Codex 识别。

## 一、它能做什么

这个 skill 用来把 AI 生成的页面从“泛 SaaS / 泛营销 / AI 味”拉回到**更克制、更清晰、更有秩序**的设计状态。

它强调：

- 信息清晰优先，少装饰。
- 近黑文字和按钮，浅灰纸感背景。
- 大标题靠字距和密度建立重量。
- 用代码块、UI mockup、数据和几何图形表达产品，不靠摄影图和营销插画。
- 动效轻，不做弹跳、夸张缩放和炫技转场。
- 字体用 Vercel 真字体 Geist（联网时自动从 Google Fonts 加载，离线落 Inter / 系统字）。
- 中文页自带适配：中文标题不会被西文负字距挤压，正文行高按中文放宽。



## 二、什么时候用

> 工程克制风格 的合适与不合适的使用场景

适合场景：

- 开发者工具、AI 工具、API / SDK / CLI 产品页面
- SaaS 落地页、定价页、技术文档首页
- changelog、技术博客、内部方法论页面

不适合：

- 强情绪营销页
- 消费品广告页
- 大量摄影图、品牌色、渐变和冲击力视觉
- 想要“热闹、炫、强刺激”的首屏

### 和 dna-anthropic 怎么选（两个都装了看这里）

| | dna-anthropic | dna-vercel |
|-|-|-|
| 气质 | 暖 · 复古 · 书卷 | 冷 · 终端 · 工程 |
| 正文 | 衬线（模拟签名感） | 无衬线 |
| 底色 | #faf9f5 暖奶油 | #fafafa 冷纸灰 |
| 层级 | 明暗色块，零阴影 | hairline 细阴影 |
| 配图 | 手绘线描 / 古典图版 | 代码块 / UI mockup |
| 适合 | 研究、阅读、教育、可信感 | 开发者工具、SaaS、精确感 |

**想要可靠的复古感，传达可被信任的感觉，用 anthropic；
想传达严谨克制的工程感，用 vercel。**

> 搭配建议：本 skill 管**长得像 Vercel**（视觉基因）；Vercel 官方另有 [web-design-guidelines](https://github.com/vercel-labs/agent-skills)（Web Interface Guidelines）管**做得讲究**（无障碍、表单、性能等 80+ 条工艺规则），两个可以同时装，互不重叠。

## 三、安装（约 5 分钟，不需要命令行）

> 安装包 dna-vercel.zip 在飞书版文档的附件里；从 repo 拿的话，直接复制 `skills/dna-vercel/` 文件夹即可，内容相同。

1. 下载解压，得到 `dna-vercel` 文件夹，里面是 4 个文件：SKILL.md、layouts.md、reasoning.md、tokens.css，缺一不可
2. 按下表把**整个文件夹**复制进去，文件夹名保持 `dna-vercel` 不变
3. 验证：问 AI 一句「你能看到 dna-vercel 这个 skill 吗？」，它确认就装好了

| 工具 | 放到哪 | 装完之后 |
|-|-|-|
| Claude Code | `~/.claude/skills/dna-vercel/`（推荐，所有项目都能用）。只想给某个项目用，就放 `项目/.claude/skills/dna-vercel/` | 新开一个对话 |
| Codex | `~/.codex/skills/dna-vercel/` | 重启 Codex |

这些以 `.` 开头的文件夹在访达里默认看不见：在访达按 **⌘⇧G**，粘贴上面的路径回车即可直达；如果 skills 文件夹不存在，手动新建一个即可。

> 📝 关于 Codex：较新版本的 Codex 官方支持 skills（我们在 codex-cli 0.133 上验证过，装好重启即生效）。如果你的版本较老、重启后仍不识别，就把下面这段发给它，直接让它读文件，效果一样。

```text
请读取并遵循 ~/.codex/skills/dna-vercel/SKILL.md。
需要布局参数时读取 layouts.md，需要推导新场景时读取 reasoning.md，写页面时复用 tokens.css。
```

## 四、用法

### 4.1 用法一：从零生成新页面

适合从零做一个新页面、新 demo、新落地页。

推荐提示词：

```text
请使用 dna-vercel skill（工程克制风格），为我生成一个 {页面类型}。

产品：{产品名}
目标用户：{目标用户}
一句话价值：{一句话说明}
必须包含：{模块列表}
```

### 4.2 改造已有页面

典型情况：页面能用，但不好看、不专业、AI 味重。

这时的目标不是换一套颜色，也不是强行改成 Vercel 官网，而是让 AI 做有判断的设计升级。

动手前只需要想清楚一件事：**这次允许 AI 动到哪一层。**

| 范围 | 允许改什么 | 适合什么时候 |
|-|-|-|
| **A. 轻量美化** | 配色、字体、圆角、阴影、按钮样式、间距 | 页面结构没问题，只是有点粗糙 |
| **B. 组件升级** | 卡片组织、按钮层级、图像表达、代码块 / 数据区、局部动效 | 页面能用，但模板感重、细节不好看 |
| **C. 结构重构** | 首屏构图、信息层级、模块顺序、分栏方式、空间密度、页面节奏 | 页面“不好看”的根因在布局和表达，不只是颜色 |
| **D. 文案语气** | 标题、副标题、CTA、说明文案的表达方式 | 文案泛营销、空、AI 味重；但不能改事实和承诺 |

经验：只说「帮我改好看点」，AI 多半只换个配色（A 档），改完你会觉得没变化。

大多数时候你真正想要的是 **B + C**；文案也明显空的话，加上 D。

对应的提示词不用复杂，说清楚两件事就行——要重构、边界在哪：

```
请使用 dna-vercel skill（工程克制风格）重构当前页面。
不要只换配色：允许调整组件细节、信息层级、首屏构图和模块结构。
```



## 五、常见问题

**Q：AI 回复「这样做就不是 Vercel 了」，还给了我几个选项？**

这是 skill 的内置行为，不是出错。

当你的要求和这套风格冲突（比如要加渐变、彩色按钮、大圆角），它会先说明后果、给几条路让你选，选一个它就继续做。



**Q：感觉 skill 没生效？**

- 提示词里显式写「请使用 dna-vercel skill」，这是最稳的触发方式
- 两个 dna-* 同装时更要点名；选哪个见上面的对照表
- Codex 装完必须重启；重启后仍不识别，就用第三节的兜底提示词，直接让它读 skill 文件
- 感觉改动范围太小、太表面：可以和ai说把内容提炼出来后，隔离之前的样式，用 dna-vercel skill 彻底重构。



**Q：我就是想要渐变 / emoji / 品牌色怎么办？**

直接提，AI 会照做，只是会先提醒你那部分偏离了这套风格。

如果整页都需要热闹、强刺激的营销感，这个页面就干脆别用这个 skill。
