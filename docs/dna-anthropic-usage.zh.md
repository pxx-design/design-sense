# 复古编辑风格 Skill 使用说明

> 这是一个让 AI 生成或改造页面时更有设计判断的 skill。安装包里的文件夹名是 `dna-anthropic`，调用时也建议保留这个名字，方便 Claude Code / Codex 识别。

## 一、它能做什么

这个 skill 用来把 AI 生成的页面从"泛 SaaS / 泛营销 / AI 味"
拉回到**像一本被认真编辑过的书**的状态——暖、衬线、克制、可信。

它强调：

- 暖奶油纸底（#faf9f5），不是显示器的白。
- 长文正文用衬线（模拟签名感）；层级靠明暗色块，全页零阴影。
- 强调像批注：一根实线下划线 + 偶尔一枚软染料小标签，不靠颜色强调。
- 插图是手绘线描 / 古典图版，不是摄影、3D 和图标库。
- 中文页自带「宋黑分轨」：中文大标题用宋体、正文用苹方。

## 二、什么时候用

适合场景：

- 研究机构 / 实验室 / 出版型组织的官网
- 长文阅读页、技术博客、论文与报告页
- AI 产品页（想显得可信、克制，而不是 hype）
- 知识型产品、教育产品、个人作品集
- 数据报告（自带「能进论文的图版」规范）

不适合：

- 强情绪营销页、消费品广告页
- 要"热闹、炫、强刺激"的首屏
- 大量摄影图、渐变、霓虹的视觉

### 和 dna-vercel 怎么选（两个都装了看这里）

| | dna-anthropic | dna-vercel |
|-|-|-|
| 气质 | 暖 · 复古 · 书卷 | 冷 · 终端 · 工程 |
| 正文 | 衬线（签名） | 无衬线 |
| 底色 | #faf9f5 暖奶油 | #fafafa 冷纸灰 |
| 层级 | 明暗色块，零阴影 | hairline 细阴影 |
| 配图 | 手绘线描 / 古典图版 | 代码块 / UI mockup |
| 适合 | 研究、阅读、教育、可信感 | 开发者工具、SaaS、精确感 |

**想要可靠的复古感，传达可被信任的感觉，用 anthropic；
想传达严谨克制的工程感，用 vercel。** 

## 三、安装（约 5 分钟，不需要命令行）

> 安装包 dna-anthropic.zip 在飞书版文档的附件里；从 repo 拿的话，直接复制 `skills/dna-anthropic/` 文件夹即可，内容相同。

1. 下载解压，得到 `dna-anthropic` 文件夹，里面是 4 个文件：SKILL.md、layouts.md、reasoning.md、tokens.css，缺一不可
2. 按下表把**整个文件夹**复制进去，文件夹名保持 `dna-anthropic` 不变
3. 验证：问 AI 一句「你能看到 dna-anthropic 这个 skill 吗？」，它确认就装好了

| 工具 | 放到哪 | 装完之后 |
|-|-|-|
| Claude Code | `~/.claude/skills/dna-anthropic/`（推荐，所有项目都能用）。只想给某个项目用，就放 `项目/.claude/skills/dna-anthropic/` | 新开一个对话 |
| Codex | `~/.codex/skills/dna-anthropic/` | 重启 Codex |

这些以 `.` 开头的文件夹在访达里默认看不见：在访达按 **⌘⇧G**，粘贴上面的路径回车即可直达；如果 skills 文件夹不存在，手动新建一个即可。

> 📝 老版本 Codex 不识别 skills 的话，把下面这段发给它，直接让它读文件，效果一样：
>
> ```text
> 请读取并遵循 ~/.codex/skills/dna-anthropic/SKILL.md。
> 需要布局参数时读取 layouts.md，需要推导新场景时读取 reasoning.md，写页面时复用 tokens.css。
> ```

## 四、用法

### 4.1 从零生成新页面

推荐提示词（**显式点名 skill 是最稳的触发方式**，尤其两个 dna-* 同装时）：

```text
请使用 dna-anthropic skill（复古编辑风格），为我生成一个 {页面类型}。

产品：{产品名}
目标用户：{目标用户}
一句话价值：{一句话说明}
必须包含：{模块列表}
```

### 4.2 改造已有页面

动手前想清楚一件事：**这次允许 AI 动到哪一层。**

| 范围          | 允许改什么                     | 适合什么时候            |
| ----------- | ------------------------- | ----------------- |
| **A. 轻量美化** | 配色、字体、圆角、边框、间距            | 页面结构没问题，只是有点粗糙    |
| **B. 组件升级** | 卡片明暗节奏、下划线强调、标签系统、插图表达    | 页面能用，但模板感重        |
| **C. 结构重构** | 首屏构图、阅读列、信息层级、留白节奏        | "不好看"的根因在布局，不只是颜色 |
| **D. 文案语气** | 标题、正文、CTA 的表达方式（零 hype 化） | 文案泛营销、空、AI 味重     |

经验：这套语言里 **D 档比想象中重要**——「编辑过的感觉」一半来自文字本身。
大多数时候你要的是 B + C + D。

```text
请使用 dna-anthropic skill（复古编辑风格）重构当前页面。
不要只换配色：允许调整卡片明暗节奏、信息层级、首屏构图和文案语气。
```

## 五、常见问题

**Q：AI 回复「这样做就不是这套语言了」，还给了我几个选项？**

内置行为，不是出错。
你的要求和这套风格冲突时（比如要加阴影、渐变、彩色徽章、橙色按钮），它会说明后果、给几条路让你选。

**Q：感觉 skill 没生效 / 用错了另一个 dna skill？**

- 提示词里显式写「请使用 dna-anthropic skill」，这是最稳的触发方式
- 两个 dna-* 同装时更要点名；选哪个见上面的对照表
- 改动太表面：让 AI「把内容提炼出来，隔离旧样式，用 dna-anthropic 彻底重构」

**Q：中文标题怎么变成宋体了 / 正文为什么不是宋体？**

刻意的。这套语言的中文适配是「宋黑分轨」：大标题用思源宋（书的题字），正文用苹方（官方中文界面的实测做法），整页排宋体过于课本感。

**Q：为什么没有阴影 / 按钮不是我的品牌色？**

零阴影和黑按钮是这套语言的灵魂（纸面是平的；出版物的强调是克制的）。
想要投影和品牌色按钮，可以直接和ai说，也可以考虑换 skill。

**Q：插图哪里来？**

skill 会用代码画带手绘质感的线描（合法默认档）。
想更进一步：换成你自己纸上画的黑墨线稿扫描件，或公版 19 世纪图版，skill 里写了怎么摆，图换了版面不用动。
