## Cultural Root（文化根）

**人文出版传统的视觉镜像——一本被认真编辑过的书。**

Anthropic 的用户是在意 AI 安全、研究、长期主义的思考者。这群人的文化记忆不是终端，也不是产品发布会，而是书：旧书纸的暖白、衬线正文的呼吸、百科全书里的铜版蚀刻图版、天然染料染出的封面布。是图书馆、大学出版社、十九世纪的科学图谱。

**一句话：内容极度前沿，表达极度古典。** 像达尔文的《物种起源》、洪堡的《宇宙》——那个时代的科学出版物严肃，但不冰冷；让人相信不是因为权威，而是因为认真。不靠 hype 说服你，靠"被认真编辑过"的样子让你信。

**跟相邻流派的区分**（同是减法，气质相反）：
- 工程克制（Vercel）＝镜像开发者对终端的记忆：冷、等宽、字距收到 -0.06em、纯灰白
- 产品戏剧（Apple）＝镜像消费者对"精致物件"的记忆：产品图当主角
- **复古编辑（Anthropic）＝镜像人文学者对书籍、图版、天然染料的记忆**：正文、插画、留白当主角，暖、衬线、字距最多 -0.02em、一整盒暖色却极克制地用

## 六种手法 — 它用什么模拟「一本被认真编辑过的书」（脊柱）

判准轴：**"这让它更像一本被认真编辑过的书 / 一个克制的研究机构，还是又把它推回了'又一个 AI 创业公司'？"**

| 手法（主 → 次） | 对应"一本书"的什么 | Anthropic 的做法 |
|---|---|---|
| ① **文案** | 它被认真**编辑过**（文字层，排第一） | 克制、精确、陈述句、零 hype 词；说感受、不解释道理；动词人话、不对仗目录体 |
| ② **排版** | 它被认真**排过** | 构图（版心/对齐/留白/一个峰）+ 排字（字阶/字距曲线/lining 数字），见下 |
| ③ **批注** | 它被一个认真的人**读过、划过** | 笔（一根实线下划线）+ 荧光笔（软染料小标签）——颜色只住荧光笔上 |
| ④ **图版** | 它被**手画 / 雕版**插图过 | 默认手绘线；hero 级郑重场合才升格点描 / 博物 plate（保持罕见）；绝不摄影 / 3D |
| ⑤ **材料** | 它用考究的**纸与颜料**装订 | 暖奶油纸 + 天然染料色板 + mono 给技术可信——颜色住这一支，是地板不是全部 |
| ⑥ **动效** | 它是纸，**不是屏** | 不浮起、不视差、不发光——克制动效本身是手法 |

**一句排序：文案是天花板（最难、最直接对应"编辑过"），颜色是地板。** 只学到 ⑤ 材料（配色字体），就是"漆对了、骨没对"。"编辑"二字首先指**文字**——把中文写成"正经编辑的中文"，本身就是在演这本书。

## 五个反直觉决策（都从判准轴推出，不是品味偏好）

**1. 正文用衬线，不用 sans。** AI/tech 圈正文清一色 sans——但核心问题不是"显得现代吗"，是"像一本书吗"。书的正文从来是衬线；sans 正文恰恰是这套语言要反的科技产品文化。**长文阅读体必须 serif**（这是圈内孤例的反潮流签名）；display 可 sans 可 serif；UI chrome / 短文本用 sans 合法。违反这条＝丢掉整个论点。

**2. 著名的 Claude 橙，不当 CTA。** 营销直觉说：有标志性品牌橙就该做主按钮。但出版物的强调是克制的——橙一旦变成"点我"，就从书的火花掉进 SaaS 的 CTA。橙的合法出场全在**内容**里（编辑层插画底、数据图两支色之一），不在**控件**上（公司站 UI 实测 0；唯一饱和火花是 globe 一点金 ×1）。按钮交给中性高对比：slate-dark 黑底 ivory 字。（产品层例外见 SKILL.md 红线：唯一主动作可橙，全站就一处。）

**3. 0 阴影。** 现代 UI 默认 box-shadow 做层级——但纸面是平的，书页没有投影。层级靠暖色块明暗混排（一排 1 深卡 + 2 浅卡）+ 1px 实线/半透明边框。**且节奏是页级的：每一屏至少一处墨色锚**（深卡 / 黑按钮 / 重墨标题），全暖浅铺开会发"粉雾"。

**4. 一盒颜料，不是一张色板。** 颜色不是来管理状态的（无 primary/success/warning），是来做"暖"的——证据在命名：manilla、kraft、oat、fig、heather 是天然染料名，不是 blue-500。实际页面 95% 是中性三色（slate ×543 / cloud ×365 / ivory ×320），颜料盒是"需要人味时取一支"。饱和度天花板 ~55%，无 neon——物理染料天生不会 neon。

**5. 字距温柔，最多 -0.02em。** Vercel 把标题狠收到 -0.06em 用密度堆重量——但出版排版是温柔的、留白奢侈的。三档：0 / -.005em / -.02em；大号 serif display 反而接近 0 甚至微正（96px 实测 +1.6px）。重量感来自留白和衬线本身，配套 section 主间距 10rem。

## 影像推理 · 选笔规则（最被低估的签名：影像是一只手画的）

**默认一律手绘笔触**（高频、暖、亲近）：会抖的单线黑涂鸦坐在满版色板上。只有 hero 门面 / 重大发布要"科学图谱的郑重感"才**升格到严谨 register**——点描蚀刻（首页 globe）或古典博物 plate（Fable 5 蝴蝶），**一页至多一处、全站保持罕见——罕见本身是生效机制**。

**为什么手绘承重（可迁移的因果）**：① 人手低科技痕迹 → 读作"人在掌控" → 压住对自主机器的恐惧；② 不完美（抖/歪）机器仿不出 → 读作诚实/手工 → 信任（光滑矢量读作量产）；③ 最先进配最原始，张力本身是"科技为人"的论点。**前提**：必须整套系统同向（serif + 纸感 + 自然色板），扔到霓虹暗色 SaaS 上＝反讽。**反向指征**：品牌资产是精度/速度/工程冷静时（Vercel、Linear 类）别用。**反模式（AI 最易犯的懒）**：用平滑 SVG 手搓"假笔触"＝把承重的诚实信号降格成装饰——宁可摆真件或不用。

风格是签名，**题材是话题性的**（地球 / 蝴蝶只是 subject 实例）：给别的产品用时题材按那个产品的内容选。

## 构图语法（token 是漆，构图是骨）

核心一句：**能逐行扫描 / 比较的内容一律左对齐；独一无二、要你停下来感受的对象才居中；居中靠稀缺生效，省着发给最强的对象。**

- LEFT 是默认：列表 / 目录 / 可逐行比较的一切钉在单一左边缘。这条管**文本行对齐**，不禁左右分栏构图（内容左 + 大插图右浮是这套语言自己的手法）
- CENTER 是例外：钉死护栏＝能逐行扫读的内容永不居中；克制默认＝居中极少、往往一页一处。配得上的只有：情绪句 / 标题板 / 唯一的使命论点 / 结尾 dark CTA
- **一个峰，一片平地**：标题不靠逐级放大建层级，靠 serif↔sans 切换、字重、位置、caps 小标签；条目标题 ≈ 正文字号（约 0.9-1.2×，护栏是绝不放大喊叫）。把整套"大字预算"一次性押在最强的那次居中上——处处是峰＝处处无峰
- **长文版面公式**：满宽居中标题板（仪式）→ 落进 640px 单列阅读 → serif w400 左 rag → 只有图和文末卡才 break 更宽。无 sidebar、绝不两端对齐
- **字重沿"说服 → 工具"递减**：企业 hero sans w700 → 营销 hero serif 大而轻 → 正文 serif w400 → 区标题 sans w600（安静节拍）

## 锚点参数：[语言本身] vs [品牌答案]

### [语言本身] — 改了感觉就变

```
正文字体：衬线（长文阅读体），不是 sans
  真身 Anthropic Serif（专有）→ 替身 Lora（官方 brand-guidelines 给定），Georgia 兜底
  原因：书的正文是衬线——AI 圈孤例的反潮流签名，违反就丢掉整个论点

页面背景：#faf9f5 暖奶油，绝不纯白
  原因：纯白属于显示器，暖奶油是旧书纸的温度

橙 #d97757：火花 / 插画底 / 数据色，不是 CTA（公司站控件实测 0）
  按钮一律中性高对比反相：slate-dark #141413 底 / ivory 字
  原因：出版物的强调克制；橙当按钮就掉进 SaaS

阴影：0 box-shadow（实测 shadows=[]）
  层级 = 暖色块明暗混排 + 1px 边框；每屏至少一处墨色锚
  原因：纸面是平的，书页没有投影

字距：温柔三档 0 / -.005em / -.02em；大号 serif 微正
  原因：出版排版温柔留白，狠字距是终端工程感

颜色思路：一盒颜料（天然染料），不是功能色系统
  中性三色承担 95%；饱和天花板 ~55% 无 neon；染料不做功能面板底
  原因：颜色是来做"暖"的，不是来管理状态的

影像：手画的图版（默认手绘，升格罕见），绝不摄影 / 3D / emoji / 图标库
  原因：手绘的不完美＝"人在掌控"，给强大抽象的 AI 祛魅
```

### [品牌答案] — Anthropic 的选择，可用同样逻辑推导新答案

```
字标：ANTHROP\C（反斜杠替 I）
  可替换：任何给纯文字字标注入一点几何/技术意外感的微改造
  逻辑：反斜杠给人文气质注入一点 code 味，平衡"太文学"

圆角：8px 主力 / 16px 卡片 / 4px 小件；按钮 8px 方圆角（pill 只给 chip）
  可替换：4-16px 区间的友好软圆角，非零非大
  逻辑：友好但不软烂；零圆角太工程，大圆角太消费品

section 间距：奢侈留白（main 10rem / page-top 12rem）
  可替换：任何 airy 编辑式大间距体系
  逻辑：留白是出版物的从容

导航：吸顶（实测 sticky）——纸感靠"不浮起不投影"维持，不靠取消吸顶
  0 阴影 + 发丝下边线即可，别加投影和毛玻璃

mono 替身：IBM Plex Mono（官方未给，取"中性偏人文"）
  可替换：任何非程序员文化标记的人文 mono
```
