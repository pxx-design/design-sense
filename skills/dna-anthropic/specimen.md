# Specimen · 官网六现场（带批注范例）

> **学什么**：分配的判断——峰怎么立、锚怎么压、目录怎么排、颜色怎么省。及格七问（SKILL.md 顶部）教你认失格，这里给你看「踩住了标准」长什么样。
> ⚠️ **学判断，不抄布局**：版式、内容、文案属于 anthropic.com / claude.com，照搬 = 违规；要带走的是每条批注里「为什么」那一层。
> 真值口径：2026-07-10 · 1440×900 视口 · 渲染后 computed-style 实测（非目测）。
> 校准图只保留「视觉整体感本身就是课」的三张（峰与锚 / 产品层对照 / 类目即 hero，已降采样）；其余现场以文字批注 + 实测值呈现，可直接访问原站对照。

## 现场 1 · 峰与锚 —— anthropic.com 首页（`specimen/home-peak-1440.png`）

1. **峰与锚两声分工**：hero 是 60.9px **sans w700** 大字（左对齐），第二屏是全宽 slate 圆角**墨色锚带**、内坐 60.9px **serif 居中**题——编辑层的 hero 用黑体立峰，衬线声留给锚带的郑重时刻（Q1：一屏一落点，两屏两种达成）。
2. **批注笔直接进 hero**：大标题里 research / products 两词带实线下划线——「笔」不是正文专利，最高声部也用同一支笔（强调语法全站一致，Q5）。
3. **整页 0 阴影、染料只有 oat ×3**：层级全靠明暗（纸底 ↔ 墨带）+ 留白，实测 11 声字号。
4. **区段全部 <1 屏**（0.43-0.99）：编辑层节奏比产品层碎而紧凑——「一屏一模块」在这门语言里是「一屏一短章」。
5. 滚动缩放动效属于「纸不浮起」的边界内（面块缩放非弹跳）；截整页图会有截断感，属动效本性不是失格。

## 现场 2 · 峰的产品层对照 —— claude.com/product（`specimen/product-hero-1440.png`）

1. **同 tone 换挡的机制**：hero 换成 64px **serif w500**（编辑层 sans ↔ 产品层 serif 正好互换）；纸底、字色、批注语法全部不变——**材料不换，姿态换**。
2. **唯一主动作实锤**：Ask Claude 按钮 = 深陶土 #c96442（非 clay 原色），全页橙控件只此一族——「橙不进控件」的产品层例外原文。
3. **手绘线稿在场**：hero 右侧粗黑抖线插画 + **一个 clay 圆点**——「一图一点 clay」「线描不填色」的官方同源证据（见 layouts.md#论点图解）。
4. **阴影的真相**：页面表面仍 0 提升影；真阴影（rgba(0,0,0,.15) 0 12px 24px）只出现在**浮层**（toast/下拉）——纸上无影，浮在纸上方的另一张纸才有影。
5. chips（Write/Learn/Code）= outline 药丸小件；pill 只给小件、控件 8px 方圆角的分工可见。

## 现场 3 · 目录两式 —— tutorials 卡式 vs news 期刊式（claude.com/resources/tutorials · anthropic.com/news，文字批注）

**卡式（tutorials，7 声）**：
1. 居中 serif 64px 峰 + 峰上方一枚**线稿小插画**（oat 染料苹果+书，16-24px 级图符的放大版）——目录页也有唯一的峰。
2. **裸卡**：302×414 无底无框无影无圆角——卡=染料图版封面 + 文字堆叠，分组全靠留白（拿掉卡片 chrome → 及格由间距补，咬合活例）。
3. 封面染料板 6 支（绿 #629987 / 桃 #ebc9b7 / 堇 #827dbd / clay / cactus / 深陶）——全部给得出油墨配方（CMYK 闸活证据）。
4. Grid/List **segmented 轨道**实测在场（浅暖轨 + 白选中片，非墨反相）。

**期刊式（news，8 声）**：
5. 52px sans w700「Newsroom」+ hero 右侧**刊头 meta 表**（三行发丝分行 + 图标）——头版刊头语法。
6. 列表行高 59-67px、`1px #d1cfc5` 发丝分行、category+date meta 小标 + sans 题 + serif 摘要——**期刊目录感的参数原文**；全页染料近零：目录页颜色最省。

## 现场 4 · 目录第三式：类目即 hero —— claude.com/blog（`specimen/blog-top-1440.png`）

1. **类目索引直接坐版面主角位**：四个 52px serif 链接（Agents / Claude Code / Enterprise AI…）+ 箭头就是 hero——没有大标语、没有配图，目录本身是峰（Q1 的反直觉达成）。
2. 下方文章条**4 栏横排 + 栏间竖发丝线**——报纸分栏语法；19px serif 卡题与 tutorials 同声（跨站一致，Q5）。
3. 与 tutorials 的分工：工具型目录（可搜索可筛选）→ 卡式 + 工具台；观点型目录（按栏目浏览）→ 类目式。**先判断目录的用法，再选目录的姿态。**

## 现场 5 · 读 —— code.claude.com/docs（文字批注）

1. **衬线标题进文档**：h1 30px serif **w400**、h2 24px serif w400——同为文档载体，Vercel 用 sans w600 补层级，这门语言用衬线本身的气质，字重反而更轻（两语言的答案相反，都及格）。
2. 全页**仅 6 声**——文档是词汇纪律的天花板；mono 14px ×56 是代码原生密度。
3. 正文列 689px ≈ 86 字符，行距 1.65 补偿——**行长与行距联动**（Q7），与 Vercel docs（90 字符 ×1.7）同一条护栏的两次独立成立。

## 跨现场三课

1. **Register 对照表**（「感觉不同、tone 一致」的机制）：

| 杆 | 编辑层（anthropic.com） | 产品层（claude.com） |
|---|---|---|
| hero 声部 | sans w700 大字 | serif w500 |
| 橙 | 控件 0（内容里才有） | 深陶土唯一主动作族 |
| 阴影 | 全页 0 | 页面表面 0；浮层真影 12/24 |
| 不变量 | 纸底 #faf9f5 · 字 #141413 · 批注笔 · 染料盒 · 发丝线 | 同左 |

   **材料与批注语法是身份，姿态参数是音量旋钮。**
2. **颜色是省出来的**：六页词汇 6-14 声、目录页染料近零、彩色全部过得了 CMYK（无一发光色）——颜色越少，每支染料越值钱。
3. **目录三式**：卡式（居中峰+裸卡图版）/ 期刊式（发丝行+刊头 meta）/ 类目式（类目即 hero+报纸分栏）——同一 tone 的三种目录姿态，按「目录被怎么用」选。
