## Landing（机构官网 / 产品页）

适配度：★★★★★ 原生 · 无需触发提示

### Hero（两种姿态，按内容选）

```
企业身份 hero（权威）：
- Anthropic Sans 替身 Poppins / ~60px / w700 / line-height 1.1 / 字距 0（实测）
- 关键词可带下划线强调（实测 hero "research" 划线——批注笔的门面用法）
营销 / 声明 hero（大而轻·全页的峰）：
- Serif 替身 Lora / 最大 96px / w400 / 字距微正 +0.016em（实测）
- 常为全页唯一居中——峰只有一个
视觉锚（可选）：一张手绘线描 / 蚀刻插画嵌暖板（不用渐变、不用产品摄影）
背景：#faf9f5 纯色；不做 dot grid（那是 Vercel 的记忆）
```

### Section 节奏

```
- section 主间距 10rem(160px)（实测）；page-top 12rem；小节 4-6rem
- 区/结构标题：sans 24px w600 恒定（实测）——安静节拍，不逐级放大
- 标题板之上可加 12px sans meta / caps 小标签
- 分区靠留白 + 1px hairline（--border-faint），不靠色块切换、不靠阴影
```

### Card / 卡片区

```
- 底：ivory-medium #f0eee6 / oat #e3dacc（UI 面板底只走中性暖阶，染料不做面板底）
- 边：1px solid slate-faded（rgba(20,20,19,0.1) ~ 0.3）（实测主力）
- 圆角 16px（实测 radius--large）；0 阴影
- 节奏（实测手法）：一排里混 1 张 slate-dark 深卡 + 2 张浅卡，明暗制造节奏
- 页级护栏：每一屏至少一处墨色锚（深卡 / 黑按钮 / 重墨标题），全暖浅=发"粉雾"
```

### 编辑式 Link List（期刊目录感）

```
- 行分隔：1px hairline（cloud-medium / slate-faded-10）（实测）
- 每行配 meta 小字：date / label · 12px Anthropic Sans 替身（实测 detail-xs）
- 分类标签用 ① meta 文字态（见 Tag 段），不用彩色徽章
```

### Nav / Footer

```
Nav（实测）：
- sticky top 0（实测纠正过"纸不吸顶"的推导）；0 阴影 + 1px 发丝下边线；不用毛玻璃
- 链接色 #141413，hover #5e5d59；nav link padding 22.4px 12px（实测）
- 右上 CTA：slate-dark 黑底 ivory 字——中性高对比，不是橙
Footer（实测较薄）：
- spark "A" 放射标 + 12px sans meta；结构默认多列链接 + hairline 顶线（推导默认）
```

### 按钮（三态 · 橙不参与任何变体）

```
- primary：slate-dark #141413 底 / ivory 字 / 8px 方圆角（暗面板上反相：ivory 底 slate 字）
- secondary：透明底 + 1px slate 实色边框 / 8px
- tertiary：透明底 + slate-faded 细边
- 按钮不划下划线；pill 只给 chip 类小件，控件一律方圆角（实测纠正）
- 尺寸从上下文推（未实测，不立法）
```

## Article（长文阅读页 · 签名场景）

适配度：★★★★★ 原生——这套语言最本命的载体。

```
- 版面公式：满宽居中标题板（仪式感）→ 落进 640px 单列阅读（实测两篇长文一致）
- 阅读正文：serif 17px / line-height 1.55 / w400 / 左 ragged（实测）——首页列表体才 20px，分语境
- 无 sidebar、无浮动模块挤占阅读轴；列块居中但列内文字永远左对齐，绝不两端对齐
- 内联链接下划线：粗 1.36px / offset 3px / 线色 #b0aea5 弱于文字（实测）——读起来像"被划过的文本"
- 标题断行用 text-wrap: balance，不用任意 ch 宽度（对中文不准）
- 数字 lining 等高（lnum pnum），serif 正文也是——别给 serif 配 oldstyle 旧体数字（实测）
- 图 / 文末卡可 break 出列宽；引用不加彩色高亮，靠留白和字重
```

## Console（工具页 / Dashboard）

适配度：★★★☆☆ 可做（离编辑式最远的形态也立得住）

```
- sans 给 UI chrome 合法——serif 签名管的是"长文阅读体"，表格 / 控件 / 状态行用 sans 不破签名
- 版心可放宽（实例：1120px）——640px 是阅读测度不是页宽法律
- 层级仍靠明暗（ivory 阶 + 1px 边框 + 深卡锚），0 阴影 0 渐变
- 状态表达降级为 muted 文字 / tag 三态，不引入功能色系统（红绿灯是 SaaS 语言）
- 染料 pill 全页保持稀缺（实例：全页唯一一枚）
- 控件切换用 segmented 轨道（见 Tag 段），不用下划线 tab（下划线只管导航级 / 内容 tab）
- 主按钮判黑不判橙
```

## 数据图版

> 「能进研究论文的图版」，不是配色 dashboard。实测源：19 张报告图 hue 聚类 + landing 活图。

```
色彩（钉死骨架）：
- 分类色相封两支：数据橙 #eb6834~#d97757 + 数据蓝 ≈#4a90e2（实测 19 图 0 张出现第三色相）
- 类目 >2：给灰阶不给新色相（实测：橙/深灰/蓝三类堆叠条）；再多用同色相 tint 阶梯（#f2a98b/#f3b094）
- 顺序数据：单色相明度阶梯（色相可另选一支染料）
- 数据色 ≠ UI token（数据蓝比 brand sky 更饱和，实测纠正）
图形词汇（克制默认）：横向条 / 100% 堆叠条 / 排名条 / 散点 / 点阵 / 细折线——Tufte 式
反模式（钉死）：dashboard widget / 甜甜圈 / 3D 柱 / 彩虹图例 / chart junk
版面构件（实测细节·默认可调）：
- 图版三层叠：页 ivory 底 → 暖卡（oat 或染料卡）→ 白/近白绘图卡；图题在卡外，slate sans 句式
- 类目标签左列右对齐贴轴；发丝浅灰网格；虚线参考线标基准；图例=右上 1px 描边小框
- 并排图版等高（svg 各守比例、卡内垂直居中）——参差不齐破"被认真排过"
- 图内文字 sans、数字 lining；0 阴影 0 渐变
```

## 插画图版（手绘）

```
L1 画什么（创造性核心）：
- 具象隐喻不画抽象：概念 → 认得出的老物件（放大镜/算盘/信封/齿轮）；强调"人主导"就画一只手
- 手绘不完美是承重信号：线抖/粗细不匀/收笔毛糙——宁可留抖，绝不描成光滑矢量（假笔触=红线）
  （一套可行的落抖配方，供参考非规定：stroke-width 1.0-2.6 混用、路径控制点 ±0.5-2px 抖动、
  收笔留断口、局部二次重描、整图 ±2-4° 歪斜——目标是"机器仿不出的不完美"，参数自便）
- 一图一概念；近单色：黑线 + 白形状，至多一支 muted 副色，颜色交给底下的染料卡
L2 怎么摆（确定性组装）：
- 两层叠 = 柔和染料圆角卡（底）+ 手绘插画（面）；白形是插画自身组成，不是垫底的纸卡
- 松散偏移、不居中不对称——速写本感靠歪斜与偏移；**手绘层收在卡内，不越出卡框**
- 比例是关键变量：给大尺寸 + 奢侈留白当视觉锚（小而挤=局促）
升格 register（何时用点描 / 博物 plate）：
- 只有 hero 门面 / 重大发布要"图谱的郑重感"才升格；一页至多一处、全站保持罕见
- 全彩博物 plate 不可手搓：走公版古典图版档案（19c 图鉴多已公有领域）或 image-gen，不冒充真件
```

## 论点图解（线稿 · 内联 SVG 可手搓的那一档）

> 三 register 分工：论点有**结构**（对比 / 象限 / 前后 / 路径）而无数据 → 用这档；有数据 → 数据图版；纯概念气质 → 手绘插画（上一节）。
> 谱系源：TRUE NAME STUDIO fable field-guide 卡片实作（三母题实测：对比图 / 2×2 矩阵 / 前后图）。

```
L1 画什么（钉死心法）：
- 图解不是配画，是把论点画成形状——先用一句话写出论点的结构
  （"A 整齐 vs B 混沌" / "两轴四格" / "之前大之后小"），再画那个形状；写不出结构就不配图
- 一图一论点；图解之外零装饰画

笔（钉死骨架）：
- 墨线 #141413 主笔 1.5-2px（细部 1 / 强调 2.5），linecap/linejoin round
- fill:none 为主——这是线描，不是色块画；暖白 #fbfaf5 做形内填充
- 图符（pictogram）：16-24px 极简墨线小符（文档线/眼睛/问号框），一格一符，不用图标库

抖有语义（接"禁假笔触"红线的正解）：
- 整齐 ↔ 抖是修辞：确定的画直（栅格、已知框），不确定的画抖（未知路径、模糊地带、手写 ?）
- 抖必须携带意思——全图无语义的均匀抖 = 假笔触（红线）；对比母题里"一边直一边抖"是这档的招牌
- 虚线是词汇：dasharray 密度表达确定性梯度（细密点=路径 / 疏虚线=待定框 / 波浪=模糊）；一图内虚线种类 ≤3

色的剂量（钉死）：
- 一图一点 clay——只点"问题/行动所在"（起点圆点、问号、箭头），绝不铺面
- 次要线用淡染料级（#b0a998 / #d8d2bf）；图底=染料浅 tint 圆角面板（两层叠规矩沿用）
- 整格反相 slate 可当图内墨色锚（"未知的未知"式的重音格），一图至多一格
- 全部色过 CMYK 闸（SKILL.md）

图文咬合（克制默认）：
- 图内小标：mono caps（英文）/ 小号黑体（中文），中文主标 + 英文 mono 副标双语对题合法
- 图注在图版卡下方一行 muted 文字；图内文字随图缩放，不入页面字阶
```

## Tag / 标签 / Segmented

```
① meta 文字（列表分类/日期）：纯 muted 文字 slate-soft，无底无框，常 caps（实测 live）
② outline chip（中性/筛选）：药丸 1px slate 描边透明底，padding ≈2px 16px，不大写（真组件）
③ 软染料 pill（稀缺强调 NEW/UPDATE 类）：染料底（如 heather #cbcadb）+ slate 大写小字 + 小轻圆角（实测 live）
   三层规则——钉死：dye 不是功能色系统 / 不用 clay / slate 文字 / 无 neon；
   克制默认：数量少、可数，"每一项都挂 = 滥用"；自由：用哪支染料、小圆角还是全 pill
④ segmented 轨道（控件级互斥切换，实测产品层）：浅暖轨道（ivory-dark）+ 选中白片，
   方圆角同按钮 8px 一族不是胶囊；"选中者更亮"不做墨反相；时间范围/视图切换用这个，不用下划线
用场铁律：pill 徽章只进固定槽位（卡角/行首），绝不撒进正文句子；句内状态降级为 muted 文字
```

## Longform（竖向长图）

适配度：★★★☆☆ 可做 · 档 1 软提示（长图不是这套语言的原生形态——它是 web 书页节奏；成品保留暖纸/serif 题字/批注/0 阴影，失去翻页感）

```
- 宽度 750px（公众号）/ 1080px（小红书）；整体 #faf9f5
- 章节切换靠留白递进（96/120/160px）+ hairline，不靠色块
- 中文题字走宋黑分轨（题字 Noto Serif SC w600 / 正文苹方），见 SKILL.md 中文适配
- 正文 16-17px / 行高 1.7 / 字距 +0.018em（中文编辑式）
- 强调用下划线（同一根笔），高亮用软染料 pill 点小词——绝不刷整句
- 无 hover / scroll 动效（导出静态图会丢）；无 sticky 元素
```

## Slides（翻页演示）

适配度：★☆☆☆☆ 偏离基因 · 档 2 中提示（书是连续阅读流，翻页是演讲节奏；成品保留纸感/serif/明暗层级，观感更像"出版社的发布会"）

```
工程骨架（与载体绑定的通用做法）：
- .slide-wrapper 100vw/100vh flex 居中；.slide aspect-ratio 16/9 + padding 5-6%
- slide 内 flex 三段式：header 锁顶 / body flex:1 min-height:0 / footer 锁底；overflow hidden 兜底
- 字号用 clamp() + em 字距；尺寸用 %/vw 不用绝对 px
风格参数：
- 底 #faf9f5；每页 0 阴影，层级靠明暗分区（可整页 slate-dark 做章节分隔页——墨色锚）
- 封面：serif 大题（中文宋 w600）+ 12px sans meta；内页标题 sans 24-32px w600 恒定
- 不用 bullet 圆点：空行 + 段落，或编辑式 hairline 行
- 翻页横向位移，无 zoom / morph / spring
```

## 响应式（最小护栏 · 断点为推断非实测）

```
- ≤960px：卡片收单列，section 间距减一档（10rem→6rem）
- ≤700px：nav 收起链接（保留字标 + CTA）；阅读列自动收窄，保持左 ragged
- 原则钉死：小屏不出横向滚动、触控目标 ≥44px、阅读正文字号不小于 16px
```
