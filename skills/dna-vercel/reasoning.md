## 手法地图 — 手法服务于 tone（脊柱）

判准轴：**"这让信息更清晰了，还是在信息之外加了什么？"**
这套语言的每个签名手法都挂在这根轴上，按离轴心远近排主次——改了顶上那个，Vercel 就不再是 Vercel；底下那个惊艳，但只是表皮。

| 手法（主 → 次） | 服务"信息更清晰"的哪一面 | Vercel 的做法 |
|---|---|---|
| ① **排版 / 字距**（灵魂 ·"排版即设计"） | 让信息自己有重量，不靠装饰堆气场 | 字距随字号收紧（48px 收 -0.06em），重量来自密度不是字重；Geist Sans+Mono 两种声音，永不外部字体 |
| ② **色彩按身份管理** | 颜色只承载信息身份，不做情绪说服 | 10 级灰阶做层级 / 7 功能色做状态 / 品牌色只在 hero，三者严格不混 |
| ③ **Material 分级压声量** | 层级清晰，但每一级都不喊 | 8 级阴影 + 圆角递增，每级精确压制；按钮用近黑 #171717 不用品牌色 |
| ④ **影像＝代码与界面** | "图"就是信息本身，不是装饰 | 不摄影、不插画，用 UI mockup / 代码块；三角形是符号不是装饰 |
| ⑤ **Hero 渐变被工程驯服** | 连最感性的时刻也要过结构过滤 | conic-gradient 被 blackoutLines 刮到只剩 ~1px 缝，像等高线 / 示波器，不像泼墨 |
| **噪音（不写成签名）** | 这些不服务"信息更清晰"，所以不存在 | 摄影 / 插画 / 大阴影 / 彩色按钮体系 / 衬线 / bounce 动效 → 详见 SKILL.md 红线 |

**一句排序**：排版是天花板（最难、最定义 Vercel），hero 渐变是地板（最显眼，但只在首页一处）。只学到渐变和灰阶，是"漆对了、骨没对"。

## Differentiation（证据，非论点）：排版即设计

以下是手法地图的可感证据，回答"和别人有何不同"；"为了做到什么感觉"看上面的手法地图。

字距收紧到 -0.06em，让标题有重量，不是大字号堆出来的气场。
背景 #fafafa，不是白——白太平，#fafafa 有纸质感。
卡片边框用 1px hairline shadow，不是实线边框——它在那里但不说话。
唯一强调色是近黑 #171717，不是蓝色不是品牌色——开发者不需要被颜色说服。

用户看完一屏，记住的是内容本身，不是设计语言。

## 五个反直觉决策（都从判准轴推出，不是品味偏好）

**1. 有品牌色，不给按钮。** 行业默认：primary CTA 上品牌色，让按钮"跳出来"。但判准轴问的不是显不显眼，是"这让信息更清晰了吗"——开发者不需要被颜色说服，行动本身就是重量。primary 一律近黑 #171717（终端文字色），secondary 白底实色边框；品牌色只在首页 hero 出现。颜色严格按身份分工：灰阶管层级、功能色管状态、品牌色管门面，三者不混。

**2. 字越大，字距收得越狠。** 行业默认：标题要气场就加大加粗。这套语言的重量来自密度，不是字号和字重——大标题负字距（48px 多数实测 -0.06em，字号越大收得越狠）。这是"排版即设计"的灵魂手法，也是最难学的一条：只学到渐变和灰阶，是"漆对了、骨没对"。⚠️ 西文签名，中文吃不了大负字距（见 SKILL.md 中文适配）。

**3. 全站最感性的一处，管得最严。** 行业默认：hero 渐变自由铺陈情绪。Vercel 全站唯一允许自由色彩的 hero，渐变却被 blackoutLines SVG 遮罩刮到只剩 ~1px 缝隙——像等高线地形图或示波器，不像泼墨。即使品牌最感性的时刻，色彩也要经过工程结构的过滤：终端文化对"美"的表达方式是精确的、结构化的。

**4. 营销页零摄影、零插画。** 行业默认：落地页靠摄影 / 插画 / 3D 撑情绪。开发者产品的"图"是界面和代码本身——UI mockup、深底 code block，代码块享有和标题同等的视觉地位；三角形是品牌符号，不是装饰。终端里没有照片。

**5. ghost 按钮看起来最克制，恰恰被禁。** 行业默认：outline / ghost 按钮＝"克制"的标配。这套语言反而判它出局——outline 是工具感的廉价版本，secondary 用白底实色边框。克制不是淡化，是精确控制声量：hairline 边界"在那里但不说话"，但每一级都必须清晰存在——8 级 Material 分级同理，不是"一个 shadow 搞定一切"，是精密分级后每一级都压低声量。

## 这套语言的推理方式

遇到任何设计决策，用这套语言的人问的是：
**"这让信息更清晰了，还是在信息之外加了什么？"**

如果是后者，去掉它，或者让它退到感知边缘。

### 色彩推理

颜色按身份管理 → 10 级灰阶（ds-gray-100~1000）做层级，官方用途分层：100-300 组件底 / 400-600 边框 / 700-800 高对比底 / 900-1000 文字图标（实测 border #ebebeb＝92%＝gray-400 档，互相印证）；7 种功能色（Blue/Red/Amber/Green/Teal/Purple/Pink）做状态，品牌色只在首页 hero 出现 → 三者严格分开，不混用。官方定义："A high contrast, accessible color system"。

### 字体推理

Geist 自研字体，两种核心声音：Sans（日常）+ Mono（代码/精确数据），永不引入外部字体 → 文字分 4 个类别：Heading（引导页面）、Button（仅按钮）、Label（单行紧凑）、Copy（多行宽松），各有 Subtle/Strong 修饰符和 Mono 变体 → 大字号字距收紧（48px 收 2.4px），重量感来自密度不是粗细 → 最常用样式是 text-label-14。

### 空间推理

内容密度由信息量决定，不由设计控制 → hero 区大留白，导航展开后是高密度链接列表，两种密度在同一页面共存 → 统一靠间距系统（4px base）保持节奏感。

### 组件推理

8 级 Material 分级系统：页面上 4 级（Base/Small/Medium/Large）+ 浮层 4 级（Tooltip/Menu/Modal/Fullscreen） → 阴影递增、圆角递增（官方口径：surface base/small 6px、medium/large 12px；tooltip 6px、menu/modal 12px、fullscreen 16px），但每一级声量都精确压制 → 按钮不用品牌色，用近黑 #171717，行动本身就是重量。
（注意两个 register：Geist Material 是**产品 UI** 系统；**营销站**语言实测是卡片 6px / 容器 8px——8px 正是 `--geist-marketing-radius`，营销专属档。SKILL.md 红线「页面表面无 12-20px 中间档」管的是营销站语言；做仪表盘类产品 UI 时 surface medium/large 12px 合法。）

### 影像推理

开发者产品的"图"是界面和代码 → 不用摄影，不用插画，用 UI mockup 和代码块 → 几何矢量图形（Vercel 三角形）是品牌符号，不是装饰。

### Hero 渐变推理

首页 hero 是全站唯一允许自由色彩的区域 → 但色彩不是直接铺陈，而是被 blackoutLines SVG 遮罩"驯服" → 背景色填充的密集线条刮掉大部分渐变，只留 ~1px 缝隙透出彩色 → 效果像等高线地形图或示波器波纹，而非泼墨渐变 → 即使在最感性的品牌时刻，色彩也经过工程结构的过滤。这是 Cultural Root 的极致体现：终端文化对"美"的表达方式是精确的、结构化的。

## 锚点参数：[语言本身] vs [品牌答案]

### [语言本身] — 改了感觉就变

```
页面背景：#fafafa，不是白
  原因：纯白太强，#fafafa 有印刷纸质感，降低视觉噪声

色彩系统：颜色按身份管理（灰阶层级 + 功能色状态 + 品牌色限 hero）
  原因：官方定义"A high contrast, accessible color system"

大标题字距：激进负值，字号越大收得越狠（-0.04 ~ -0.06em，48px 多数实测 -0.06em）
  原因：重量感来自密度，不是字重粗细
  ⚠️ 这是西文签名——中文吃不了大负字距，见 SKILL.md「中文适配」

字体系统：4 类文字 × 2 种声音，永不引入第三种字体
  Sans（日常）+ Mono（代码/精确）· 真身 Geist / Geist Mono 已上 Google Fonts（OFL 开源），直接用；离线兜底 Inter / JetBrains Mono
  Geist 无中文字形：中文落系统人文黑体（苹方/雅黑）——Vercel 无官方中文界面，按「工程感中文 = 系统黑体」通例，不另载 CJK webfont
  原因：不是"一套字号表"，是完整的文字工程系统

Material 分级：8 级，每级都克制
  圆角分级：页面表面 6px / 8px；浮层 12-16px；按钮 pill
  阴影 hairline 是基础，超出 hairline 都"过响"
  原因：精密分级后每一级都压低声量，不是"一个 shadow 搞定一切"

Hero 渐变：三层复合 conic-gradient + blackoutLines SVG 遮罩 + 白色三角形
  原因：即使品牌最感性时刻，色彩也必须经过工程结构过滤
```

### [品牌答案] — Vercel 的选择，可以用同样逻辑推导新答案

```
按钮圆角：100px pill
  可替换：6-8px（更偏工具感）
  逻辑：pill 传递圆润现代感，但开发工具也可以选更硬的圆角

Nav 高度：64px
  可替换：保持足够触控区域，不要低于 44px
  逻辑：64px 给了导航呼吸空间，不显廉价

Gray scale：10 级中性灰
  可替换：任何完整的中性灰系统
  逻辑：10 级系统比 5 级更细腻，适合复杂产品界面的层级表达
```
