# Specimen · 官网四现场（带批注范例）

> **学什么**：分配的判断——峰放哪、谷敢多空、密怎么收、读怎么护。及格七问（SKILL.md 顶部）教你认失格，这里给你看「踩住了标准」长什么样。
> **怎么用**：渲染目检时不确定「有峰 / 有节奏」是什么样，回这里对照同类现场。
> ⚠️ **学判断，不抄布局**：四页的版式、内容结构、文案属于 vercel.com，照搬 = 违规；要带走的是每条批注里「为什么」那一层。
> 真值口径：2026-07-10 · 1440×900 视口 · 渲染后 computed-style 实测（非目测）。
> 校准图只保留「视觉整体感本身就是课」的现场（峰的现场感 / 节奏全貌，已降采样）；其余现场以文字批注 + 实测值呈现，可直接访问原站对照。

## 现场 1 · 峰 —— home hero（`specimen/home-peak-1440.png` · 全页 `home-full-1440.png`）

1. **整屏只有一个 display**：64px「Agentic Infrastructure」（w400 · -0.06em），屏内第二大的字是 16px 按钮——第一落点毫无歧义（Q1）。
2. **峰值比的教训**：全页 top1/top2 = 64/56 = 仅 1.14，数字很小，但那些 56px 区段标题在三屏之外——**峰是逐屏的判断，不是全页一个数**。别拿全页比值凑数，问「这一屏谁是主角」。
3. **层级零颜色**：整屏黑白灰 + 一个黑三角。层级 = 字号跨度 + 留白（咬合纪律：拿掉颜色 → 字阶留白补）。
4. **峰旁边配 label 声**：右侧三行 11-12px mono uppercase 正字距——用「小而正」衬「大而负」，64px 与 12px 之间不站人（Q4 对比的决绝）。
5. **谷就在峰旁**：hero 区段 0.93 屏，文字只占屏面约四分之一（Q6）；底部 logo 带一行排 7 个、全部去彩转黑——密的一笔 + 同角色同待遇（Q5）。

## 现场 2 · 谷 —— sandbox（vercel.com/sandbox，文字批注）

1. **一屏一模块**：九个区段七个落在 0.78-1.25 屏（实测 1.0 / 1.16 / 0.98 / 0.78 / 1.17 / 0.96 / 1.25）——滚动停点 = 论点边界（规则见 layouts.md#Section）。
2. **区段间留白 96-144px**（首页同档更高到 208-276px），明显大于块间距——Q2 三档间距在页面尺度的实证。
3. **词汇纪律**：整页仅 12 种字号服务九个区段；正文主力 13px ×219——量大靠一档复用，不靠新字号（Q4/Q5）。
4. **mono 也能当一次峰**：48px Geist Mono display 全页仅一处——工具可以破格，剂量必须唯一。

## 现场 3 · 密 —— pricing（vercel.com/pricing，文字批注）

1. **密的真相**：14px ×481。密不是字号变多，是**同一档大量复用 + 行内收紧**；全页仍只有 9 种字号（Q4/Q5）。
2. **查阅型例外**：价格矩阵一个区段 12.6 屏——「一屏一模块」的合法例外，靠分组表头 + 局部密度维持扫读（layouts.md#Section 例外条）。
3. **密被疏包着**：矩阵前后的叙事区段仍是 0.28-1.31 屏——节奏没有因为密而丢（Q6）。
4. **mono 管数据**：11px w600 / 13px w500 mono 标签管表头与单位——数据的声音在密区最响。

## 现场 4 · 读 —— docs/connect（vercel.com/docs/connect，文字批注）

1. **页底纯白 #ffffff**（不是 #fafafa）——docs 载体例外：长文阅读用更亮的纸面。
2. **小空间层级更决绝**：h1 40px（-0.06em · w600）→ h2 24px → 正文 16px，文档峰值比 40/24 = 1.67 反而比营销页陡；标题改用 w600——字号杆变短，字重补上（咬合在读载体的形态）。
3. **行长×行距联动**：正文列 716px ≈ 90 字符，超出 45-75 护栏——但行距 1.7 补偿。护栏是联动关系，不是死数（Q7 活例）。
4. **三栏各守各的一致**：左侧栏 14px 一档到底，右 TOC 同字号灰阶降档，正文 inline code 14.4px mono（0.9em 相对）——同角色同待遇（Q5）。
5. **读载体的节奏变体**：文档天然密度均匀，停顿靠标题梯度 + callout 卡片制造，不靠大留白（Q6 不是只有一种实现）。

## 跨现场两课

1. **峰值比是判断不是数字**：同一个 1.14，全页看是失格、逐屏看是满分。量化指标只能当线索，最终问七问 Q1。
2. **一屏一模块 + 例外**：叙事区段贴一屏走，查阅内容按分组走——先判断内容是「论点」还是「查表」，再选构图单位。
